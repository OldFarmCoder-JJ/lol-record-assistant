# 腾讯 101 国服海克斯版（2026-10-06）

打开左侧“英雄攻略”，选择海克斯大乱斗。海克斯英雄排行、英雄强化推荐、出装与技能加点已改为腾讯 101 国服数据。召唤师峡谷支持 OP.GG 全球/韩服、腾讯 101 国服，以及三服共同强势和克制对位比较，详见《国服峡谷与三服对比说明》。

## 使用与数据含义

- 海克斯使用国服统一数据，隐藏原来的韩服/全球和段位筛选；召唤师峡谷切回后恢复原筛选。
- 英雄榜显示国服胜率、登场率与 T0–T4 梯队。梯队按官网角色分组及比例计算，取英雄的最佳角色梯队。
- 强化仅显示所选英雄的列表，支持名称/描述搜索和白银、黄金、棱彩筛选。评级为接口明确提供的 S/A/B/C/D；接口缺少评级时显示“—”，不自行编造评级。
- 全部品质和单独品质各自使用官网对应的评级、排名、选取率。腾讯该英雄接口没有强化胜率或强度评分，因此不显示这两项。
- 出门装、鞋子、核心出装、其他成装附带国服胜率和登场率；加点来自同一英雄接口。没有返回的召唤师技能不填入其他来源。
- 标題与右上角标注统计日期。正常读取前一天的英雄榜；若该日未发布，尝试前两天/前三天并显示实际日期。
- 下方链接打开当前英雄的腾讯 101 海克斯详情页。

## 来源与缓存

公开网站：https://101.qq.com/#/rankings/hextech

统计接口：`mlol.qt.qq.com/go/battle_info/odp_proxy/fuwen_aram_hero_rank_v2`、`fuwen_hero_rank`。
静态英雄与强化定义、强化大图：`game.gtimg.cn`。

腾讯请求直接访问国内服务器，不使用应用的 OP.GG 专用代理开关。统计缓存 15 分钟，英雄和强化静态定义缓存 24 小时，存于 `%APPDATA%/Seraphine/cache/tencent-hextech`；磁盘读取与 JSON 解码在工作线程执行。

英雄、装备、符文、召唤师技能、强化、头像和原画统一复用 `%APPDATA%/Seraphine/cache/game-icons`，升级 EXE 目录后继续使用。优先读取本地缓存（包括旧目录缓存），缺失时从 LCU 客户端取素材。同一路径的并发请求合并，下载完成后原子写入。海克斯强化须同时匹配 ID 与中文名或图标文件名才复用客户端素材；客户端缺失时才用腾讯补充。已经缓存的腾讯大图继续复用，存于 `tencent-hextech-icons`。

列表先显示、图标后台加载，界面每次最多更新 16 张图标，已经显示的图标不重复解码。首次获取未缓存的统计仍受腾讯接口速度影响。旧 OP.GG 海克斯统计缓存不复用。

源代码：`app/lol/tencent_hextech.py` 为国服适配器；`opgg.py` 保留统一调用入口。原来的 OP.GG 海克斯页面解析器不再被运行模块调用。

## 验证与边界

已验证 2026-10-05 国服数据：173 个英雄、安妮 108 条强化、盖伦 138 条强化。全部品质的每条推荐排名、评级、选取率逐一与腾讯接口比对；英雄切换、三品质筛选、搜索、图标解码、独立实例磁盘缓存、慢图标不阻塞列表均通过。

召唤师峡谷原接口仍返回 173 个英雄。界面测试使用占位物品图标隔离 LCU，强化图标使用真实腾讯资源；真实物品图标由 LOL 客户端接口读取。未进行实际对局 BP 验证。海克斯推荐仅供查看，不自动选择游戏内强化。

桌面版另存新目录，保留之前版本。保留 Qt 中文安装路径兼容处理和深色卡片/彩色评级/图标底板。
