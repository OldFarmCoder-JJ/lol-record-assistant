# BP 选角助手 MVP

入口：主窗口左侧「英雄攻略」，顶部选择 Ranked（召唤师峡谷）。

1. 启动英雄联盟客户端，进入选人。面板通过已有 LCU WebSocket 订阅刷新双方选角。
2. 我方按接口提供的分路显示，标记本人、预选和锁定。敌方只展示接口已公开的锁定英雄，首先放入「待确认」。
3. 拖动敌方英雄到上单、打野、中单、射手、辅助。目标位置已有英雄时交换位置。也可点击英雄，选择分路，点击「移到此路」；键盘可选择英雄后按 Enter。
4. 点击「查看 Counter」。顶部同步到对应分路，按所选数据源、段位查询推荐。现有推荐功能支持国服、全球、韩服和三服比较。
5. 禁用和双方已选英雄会被过滤；选角刷新保留手动分路。调整当前对手分路会清空旧推荐，需要重新查询。结束 BP、客户端删除选角会话时清理面板。

本版先完成读阵容、手动对位和推荐闭环。尚未实现敌方自动分路推断、个人熟练度/拥有英雄筛选、全阵容评分。所有拖动仅调整助手内部显示，不操作游戏选人。

## 2026-10-09 修正

- 双方阵容主动加载英雄头像，优先走本地客户端；客户端图片不可用时尝试公共图片源并缓存，不再只读已有缓存。
- 你预选或锁定英雄，并把敌方英雄放到你的分路后，自动显示「你的英雄 vs 对位英雄」胜率。即使已经选中、胜率低于 50%，也保留自己的对位统计。
- 切换英雄、对位分路、数据源或段位时重新查询；丢弃旧请求的过期结果。可点击「刷新对位」重试。
- 未公开的样本量和没有统计的组合明确标注；三服各自展示胜率，不计算未经定义的平均胜率。样本量、日期和段位说明可悬停查看。
- 验证：无缓存时主动加载双方图片；自己的劣势对局、缺失组合、选角变更和迟到响应；真实公共英雄头像和真实国服凯尔对盖伦上路数据。2026-10-09 查询显示 16.19、统计日期 2026-10-08，凯尔一侧胜率 55.88%。真人 BP 尚待验证。

对位胜率是整局对局统计，不保证线上一定好打。国服没有公开样本量时不编造样本量。国服最新版本未发布统计时尝试上一版，并显示实际查询版本；三服指定版本比较不会跨版本回退。

验证：模拟 LCU 会话验证锁定识别、刷新、拖放、位置交换、禁选过滤、重置、结束清理和亮/暗主题布局。国服真实查询验证盖伦上单 Counter，过滤禁用凯尔和已选盖伦；2026-10-08 查询获得 16.19 数据、统计日期 2026-10-07。当前环境没有运行 LeagueClientUx，因此尚未进行真人 BP 的端到端验证。
