# 战绩复盘与克制头像

## 选谁打他：从头像直接打开攻略

在峡谷排行榜右侧点击克制头像，打开的是该头像英雄的攻略，沿用当前排行的分路与数据源。点击整行仍然打开该行英雄；查看完攻略可返回原排行，保留原有排序和滚动位置。

头像支持 Tab 聚焦后按回车或空格打开；右键仍可收藏。已禁用、已选或暂不可选的英雄也可以查看攻略，按钮不会执行选人、禁用或交换操作。

选人期间，头像上的细虚线环提示状态：

| 外观 / 提示 | 依据与含义 |
| --- | --- |
| 红色虚线环：已禁用 | 当前选人会话已确认的禁用列表或已完成禁用动作。 |
| 灰色虚线环：已锁定选择 | 已完成的选人动作；悬停预选不算锁定。 |
| 灰色虚线环：暂不可选 | 客户端返回有效可选列表，但其中未包含该英雄；不推测未拥有或其他原因。 |
| 悬停显示当前可选 | 客户端明确返回的可选列表包含该英雄，且没有禁用、已锁定证据。 |
| 悬停显示未确认 | 可选接口缺失、失败、格式异常，或处于空列表过渡状态。 |

状态只作用于峡谷克制头像，不改公共排行次序、不隐藏对面目标，也不改变海斗备战席与前三金框的语义。退出选人、断开客户端或换客户端时清空；迟到的读取结果不会重新点亮旧状态。相同锁定状态的计时与预选通知不重复请求接口。

## 战绩统计：最近20／50／100场

点击「战绩统计」，在「最近对局」旁选择场数。可以分别查看全部排位、单／双排、灵活组排和海克斯大乱斗。更改范围时立即展示当前已读取记录；连接客户端且数量不足时尝试补读，无需重新打开页面。

逐场列表包括英雄、结果、K/D/A、分路、队列、时长和时间。双击仍可打开该场英雄的对应攻略，优先使用已记录分路。海斗打开海斗攻略。

- K/D/A依次是击杀、死亡和助攻；0死亡显示0，不计算无限比率。
- 时长显示为分:秒。
- 缺失字段显示“—”，不补成0。旧缓存仍可使用，刷新后补齐接口返回的近期记录。
- 重开和待确认结果单独展示，不算失败。
- 50／100场按当前所选队列筛选；官方历史补读按同一队列和场数目标继续分页，不再固定停在20场排位。

每次最多读取近期200场混合队列记录，本地累计最多保留2000场；接口可能重复分页、返回更少记录或暂时不可用。数量不足时明确显示实际已读取场次。它不是完整生涯记录，也不会为了凑足场数复制记录或混入其他队列。

## 英雄使用统计

按使用场次、最近使用时间排序，玩过1场也显示。新增场均K/D/A，悬停该单元格可查看有效样本数。只对有完整KDA字段的非重开记录求平均；缺失场次不按0计算，也不做个人胜率或熟练度排名。

换账号后使用各自的缓存和收藏；上一账号的迟到资料和战绩结果不会覆盖当前账号。排行上的近期标记仍按每个模式最近20场有效对局统计，不随战绩页的20／50／100场选择变化。

## 设计与验证依据

本轮从仓库已有升级规划和实际代码出发，优先打通“看见克制候选 → 查看攻略”和“最近战绩 → 按队列复盘”。参考 [OP.GG官方桌面功能介绍](https://op.gg/desktop/en/games/lol) 中按模式查看战绩及英雄攻略的组织方式，沿用独立战绩页与紧凑排行，不增加常驻侧面板。

可选状态通过客户端只读会话和可选列表获取。接口存在性参考 [LCU API文档](https://lcu.kebs.dev/)，不同客户端的可用性由运行时决定；未确认时不推测。局内三个海克斯候选的获取仍未验证，不恢复此前的局内小窗。

本轮通过16项模型与界面回归、浅深色、125%缩放、640px高窗口、完整源码启动，以及公开国服/海斗排行读取。固定模拟负载下，排行热切换中位约94ms、返回已加载排行约17ms，行控件保持225个；这是本机模拟数据结果，实际网络和机器会影响速度。

验证当时没有运行中的英雄联盟客户端，真实选人和新版战绩字段的现场验收未完成。截图中的选人状态与个人战绩明确标注为模拟演示；公开排行是实时接口读取。安装包另行验证清单、校验值、独立启动与更新流程。
