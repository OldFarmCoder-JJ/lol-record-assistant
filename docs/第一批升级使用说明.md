# 第一批升级使用说明

目前为源码开发版，运行根目录的「启动源码版.cmd」。E盘安装版和桌面快捷方式仍使用已安装的 v1.3.3。

## 收藏与近期玩过

- 连接客户端后，英雄头像右下角的星形按钮可收藏／取消收藏，也可右键英雄行或克制头像操作。
- 蓝色星标表示已收藏；绿色「近」表示在当前账号已读取的近期同模式记录中玩过。鼠标悬停查看场次、胜负和统计范围。
- 收藏按当前账号单独保存，换号后不会沿用上一个账号的收藏或近期记录。
- 排位和海斗分别统计最近20场有效同模式对局。近期玩过不等于熟练；排位个人胜率不作为海斗个人胜率展示。
- 收藏只增加标记，不改变 Counter 定位、普通排行名次、海斗胜率顺序或前三金框的含义。

## 自动跟随

- 勾选排行上方「自动跟随」后，进入已支持的选人模式时，助手跟随海斗／峡谷和客户端明确分配给本人的分路。
- 手动切换模式或分路后，显示「跟随已暂停」，本局尊重你的浏览选择；重复选人通知不会再抢回。
- 取消后重新勾选可以立即恢复；下一次进入选人也会恢复。开关设置会保存。
- 查看「我的英雄」时可以同步顶部选择，但不会自动离开战绩页；使用「返回排行」继续。
- 未确认或未支持的队列不自动改选；对面英雄分路仍不推测。

## 缓存与重试

- 当前筛选有可用本地缓存时，先显示该列表，同时显示「缓存时间 · 正在更新」。
- 网络失败时显示「暂用缓存 · 更新失败，可重试」，保留同条件的旧列表与原数据版本。点击「刷新」重试。
- 没有当前条件的缓存时显示加载或错误提示，不拿另一模式／服务器／段位／分路的旧列表充当结果。
- 缓存保存的是公共排行，不包含账号身份或个人战绩；默认最多32份、最长保留7天。头像缓存丢失时使用内置占位图。
- 「已读取」指助手本次完成读取，数据自身的统计日期和版本仍以右上角及其悬停说明为准。

## 本次验证范围

真实客户端已验证国服打野排行、最近20场排位接入、收藏和近期标记，以及浅色／深色布局。自动跟随、手动暂停、漏通知后的恢复、断网缓存、换号、迟到回复等使用可控事件与故障场景验证；没有自动选人或改变游戏状态。
